# Tessel releases

Binary releases of **Tessel** (Shift Planner): a small Windows program for a team's shift planner. One executable, data in plain JSON files on a shared drive, one editor at a time.

- **Download:** take `tessel.zip` from the [latest release](../../releases/latest) and check it against `SHA256SUMS.txt`. Unzip it into a shared folder and run `avvia.bat`. `LEGGIMI.txt` in the package is the user guide (in Italian).
- **Updates:** Tessel looks at this page for newer releases and offers to install them; the package is verified against its SHA-256 before anything is replaced.
- **Source code:** not published. This repository only hosts the release files.
